preamble.txt
# Why this course exists
With the increasing demand for automation in cloud computing, new trends and
topics are developed each year alongside upcoming trends expected in the near
future. This course focuses on the Azure cloud platform, presenting a top-to-down
view of Azure and PowerShell — from application and administration through to
programming and infrastructure. It covers programming techniques for Azure
cloud and large-scale distributed systems that form the cloud infrastructure.
Students gain in-depth, hands-on skills in automation and configuration
management for Azure services, aligned to the course curriculum.

Course Content — Theory

5 modules · 6 hours each. Click a module to expand.
01Introduction to Windows PowerShell6 Hrs
Getting started with Windows PowerShell: introduction, setting up the lab environment, installing Windows PowerShell, starting and stopping PowerShell, finding available commands, limitations of CMD.exe, the GUI emphasis in Windows, previously attempted solutions.

The Windows PowerShell approach: a new architecture, a new cross-tool approach, namespaces as drives, extensibility and backward compatibility, the object-based approach in PowerShell, consistent verb-noun naming scheme, the upgrade path to C#, working with errors, debugging in PowerShell, and additional PowerShell features.
02Windows System with PowerShell6 Hrs
Using the interactive PowerShell: PowerShell's two command-line parsing approaches, exploring the Windows system with PowerShell, using abbreviated commands, working with object pipelines, pros and cons of verbosity, snap-ins, profiles, aliases, prompts, and preference variables. Parameters, and variables as parameters.
03PowerShell Cmdlets6 Hrs
Filtering and formatting output: Where-Object, Select-Object, default formatting, Format-Table, Format-List, Update-FormatData and Update-TypeData cmdlets, Remove-Item, the -WhatIf, -Confirm and -Verbose parameters, Windows PowerShell providers, Get-PSDrive, Set-Location, Get-ChildItem, Get-Location, Get-Content, Measure-Object, New-Item, New-PSDrive.

Using PowerShell tools for discovery: exploring system state, environment variables, the current application domain, services, and the Get-Service cmdlet.
04Errors and Exceptions6 Hrs
Working with errors and exceptions: errors, error-related variables, the Trap statement, common parameters, handling syntax errors, Set-PSDebug, Write-Debug, tracing, path names in Windows PowerShell, and simple tasks with folders and files.

Working with WMI: introducing Windows Management Instrumentation, WMI essentials, exploring WMI, choosing WMI or CIM, using Get-WmiObject, and using Get-CimInstance.
05PowerShell DSC6 Hrs
Introducing PowerShell DSC: introduction to PowerShell DSC, DSC high-level overview, DSC features, PowerShell v4/v5/v6 DSC, the PowerShell ISE, partial configurations and dependencies.

DSC architecture: overview, push and pull modes, the general workflow, an example workflow, configuration data, the Local Configuration Manager, the DSC pull server, and deployment considerations.
